# msServer 3.0.2 发布说明

傻瓜式 DVB 直播 / 转码一体机：收流、解扰、转码、出流、读卡、防火墙、授权——Web 一站管理，单二进制部署。

## 一、整体优势

- **单文件交付**：管理 Web 嵌入二进制，内存加载，无需散落前端目录
- **CentOS 7 / Ubuntu 22.04+** 可运行；正式包以 el7 容器编译为准，兼容老系统
- **守护进程**：支持 `-d` 后台、`-stop` 停止、`-install` / `-uninstall` 系统服务
- **崩溃隔离**：DVB 适配器异常不拖死主进程；非 UTF-8 JSON 等异常不 terminate
- **多语言界面**：简体 / 繁體 / English
- **授权激活**：设备指纹 + 授权码，未激活引导授权页

## 二、DVB 接收

- 支持 **DVB-C / DVB-T / DVB-S**（含 C 波段 LNB、通用/高级调谐参数）
- 频点管理：锁频、信号质量、频道列表、启停热更新
- 扫描入库、频道自定义 slug、同频点多频道并行
- 扫描后可自动开流；台湾等台名乱码处理
- 多客户端共享码流（TsHub 零拷贝扇出），HTTP 背压与连接上限可调

## 三、CAS / OSCam / CAM

- **内置 OSCam** 配置与联动
- **USB 读卡自动绑定**，少手工折腾
- CAM 配置、频道解扰绑定；配置变更可定向热生效，不整台打断

## 四、转码引擎（内置 FFmpeg）

- **透传 / 软解硬编 / 全硬解硬编** 等模式
- **NVIDIA（NVENC）**、**Intel** 硬件转码；概览页显卡占用/编解码/显存/温度
- 去隔行（含 bwdif_cuda 等）；NVENC 画质相关选项（如 spatial-aq）
- 多音轨、字幕压制 / 打包音轨
- **AV1 可过 MPEG-TS**（HTTP-TS / mskey）
- 源探测异步，不卡死管理界面；并发转码路数可配（默认可不限制）
- 频道启停/重启走后台队列，Web 不假死

## 五、出流能力

| 方式 | 说明 |
|------|------|
| **HTTP-TS** | `/live/`、`/tvlive/*.ts` 长连接单播 |
| **HLS** | TS / fMP4；推荐写 `/dev/shm` 内存盘 |
| **UDP / RTP 组播** | 地址模板、TTL、网卡绑定 |
| **RTMP** | 推流 / 拉流（nginx-rtmp），可独立鉴权 |
| **mskey** | 私有 KCP + AES-GCM；`mskey://` 拉流，端口热生效 |
| **Nginx HLS 边缘** | 独立端口静态切片，不转发管理 API |

- **同开 TS + HLS 更稳（3.0.2）**：tee 主流 `pipe:1` 优先；HLS 等支路失败自动退避重连，避免单播空流
- 出流命令保持简单：`[f=mpegts]pipe:1|ms+hls:auto`
- HLS CDN 回调 / 预热、切片通知；防盗链密钥 `?k=`、nginx `secure_link` 签名；本机 `127.0.0.1` 免鉴权便于联调

## 六、监控与安全

- 实时 **TS 拉流连接**（频道、IP、时长、流量）；**同机多连接独立计数（3.0.2）**，不再「有流无连接」
- IP 封禁；出流白名单可与防火墙联动
- **防火墙管理**：ufw / firewalld / iptables，端口与 IP 策略可视化
- 登录会话 Cookie；改密与账户管理；敏感健康信息不裸奔

## 七、系统与运维

- **概览**：CPU / 内存 / 网卡吞吐、运行时间、接收卡与转码路数
- **网络** 配置、**NTP**、**日志**、**备份恢复**
- **Nginx** 自动生成 / 测试 / 重载 / 重启
- 配置 JSON 持久化（`ms-dvb.json`），首次可生成默认；热更新路径尽量不整进程重启
- Web 资源 gzip 嵌入，页面加载更轻

## 八、3.0.2 相对增强（摘要）

1. HTTP-TS 与 HLS 双开时单播更可靠（tee 主流/支路策略）
2. 监控连接按会话唯一 ID，本机 pub 拉本机 TS 也能正确显示
3. 产品版本号：`msServer/3.0.2`

## 运行环境建议

- 系统：CentOS 7+、Ubuntu 22.04+
- 硬件转码：NVIDIA 或 Intel 核显/独显（驱动齐全）
- HLS 高负载：优先 tmpfs（如 `/dev/shm/msdvb`）
- 默认管理端口：**9988**

## 升级说明

替换 `msServer` 二进制后重启服务；若同步更新了内置 FFmpeg overlay，请一并替换 ffmpeg。授权与 `data/` 配置一般可保留。
